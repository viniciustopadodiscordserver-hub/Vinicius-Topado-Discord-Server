# 🎮 Website Oficial - Comunidade ViniciusTopado Discord

Este repositório contém o código-fonte da landing page oficial do servidor de Discord do **ViniciusTopado**. O site foi desenvolvido para centralizar informações sobre a comunidade, regras, benefícios de impulsionadores, sistema de níveis e busca interativa de comandos dos bots.

---

## ✨ Funcionalidades

- **Fundo Animado com Partículas:** Efeito contínuo de gradiente e partículas/vagalumes flutuantes em tempo real via HTML5 Canvas.
- **Busca de Comandos:** Tabela com filtro dinâmico em JavaScript para pesquisar comandos da Loritta e Flavibot em tempo real.
- **Ações Rápidas:** Acesso direto para entrar no Discord (`discord.gg/Jd7N5sRvD8`) e acessar o canal do YouTube.
- **Navegação Suave:** Scroll fluido para navegação entre seções (Regras, Impulsionadores, Níveis e Comandos).
- **Design Responsivo:** Adaptado para navegação em celulares, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura e marcação semântica.
- **CSS3:** Estilização com variáveis, Flexbox, CSS Grid e animações `@keyframes`.
- **JavaScript (Vanilla):** Manipulação da API Canvas e filtro de busca na tabela.
- **FontAwesome:** Biblioteca de ícones interativos.
